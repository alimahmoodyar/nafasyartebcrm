رابط ویندوز نفس‌یار — نسخه ۰٫۲٫۱

بسته نصب برای کاربر ویندوز؛ همراه کد منبع و آزمون‌ها. این بسته EXE مستقل نیست و نصب آن به Python نیاز دارد.

این نسخه چه کاری انجام می‌دهد؟

فهرست پنجره‌های باز ویندوز را نمایش می‌دهد. پنجره حسابداری را خودتان انتخاب می‌کنید؛ متن‌های قابل خواندن و در صورت انتخاب شما، تصویر همان پنجره در بخش «اتصال حسابداری» سامانه اصلی نمایش داده می‌شود. نرم‌افزار کلیک، تایپ، ثبت، اصلاح یا حذف سند انجام نمی‌دهد.

گزارش‌گیری خودکار، ورود به منوهای حسابداری، دریافت کل دیتابیس، تحلیل اسناد و اجرای روزانه هنوز پیاده‌سازی نشده است. نتیجه این مرحله فقط نشان می‌دهد کدام اجزای صفحه قابل خواندن‌اند؛ از آن نمی‌توان درباره درستی اسناد یا عملکرد کارکنان نتیجه گرفت.

نصب قدم‌به‌قدم

  1. از رایانه ویندوزی که حسابداری روی آن اجرا می‌شود استفاده کنید. هدف این بسته Windows 10/11 و Python 3.11 یا 3.12 است.
  2. فایل nafasyar-windows-bridge-0.2.1.zip را دانلود کنید. روی آن راست‌کلیک و Extract All را انتخاب کنید؛ نصب را از داخل ZIP اجرا نکنید.
  3. در پوشه استخراج‌شده روی INSTALL.cmd دوبار کلیک کنید. نصب‌کننده ابتدا پایتون موجود را از طریق راه‌انداز، مسیرهای معمول نصب، رجیستری و PATH پیدا می‌کند. اگر پیدا نشود، همین راهنما باز می‌شود. برای ویندوز معمول ۶۴بیتی فایل دقیق Python 3.12.10 برای ویندوز ۶۴بیتی و برای ویندوز ۳۲بیتی فایل ۳۲بیتی را از سایت رسمی بگیرید. نام فایل ۶۴بیتی باید python-3.12.10-amd64.exe باشد. نصب فقط Python Install Manager یا نسخه دیگری مثل 3.14 برای این بسته کافی نیست. در نصب، Tcl/Tk را فعال نگه دارید؛ سپس INSTALL.cmd را دوباره اجرا کنید. اگر قبلاً Python 3.12 نصب است ولی Tcl/Tk ندارد، با Modify آن را اضافه کنید.
  4. نصب، محیط مجزای Python و وابستگی‌ها را از PyPI دریافت می‌کند؛ به اینترنت نیاز دارد. پایان موفق با پیام Installation completed و میان‌بر Nafasyar Bridge روی دسکتاپ مشخص می‌شود.
  5. حسابداری را باز کنید. در رابط «شروع اتصال» و سپس «کپی کد» را بزنید. با «بازکردن سامانه» به سایت بروید.
  6. در سامانه اصلی نفس‌یار با حساب مدیر وارد شوید. از منوی مدیریت، «اتصال حسابداری» را باز کنید؛ کد را وارد و «برقراری اتصال» را بزنید. اگر مرورگر اجازه اتصال محلی خواست، این اجازه برای ارتباط با رابط همین رایانه لازم است.
  7. «دریافت پنجره‌های باز» را بزنید، پنجره حسابداری را انتخاب کنید، سپس «خواندن همین پنجره». تصویر به‌صورت پیش‌فرض خاموش است.

رابط کلید API نمی‌خواهد. کد اتصال، رمز حسابداری نیست و با شروع مجدد عوض می‌شود. اتصال فقط از همین رایانه ممکن است؛ بازکردن سایت در گوشی به رایانه شما متصل نمی‌شود.

اگر نصب متوقف شد

در نسخه ۰٫۲٫۱ علت تشخیص‌ندادن پایتون، نسخه پیدا‌شده و خطاهای نصب در فایل INSTALL-LOG.txt کنار INSTALL.cmd نوشته می‌شوند. این فایل را برای بررسی بفرستید. گزارش شامل مسیرهای محلی ویندوز و خروجی نصب است؛ اطلاعات حسابداری خوانده نمی‌شود. بسته جدید را در پوشه‌ای تازه Extract All کنید تا فایل‌های نسخه قبلی با آن مخلوط نشوند.

اگر Python در مسیر سفارشی نصب شده، همکار فنی می‌تواند مسیر کامل python.exe را به INSTALL.cmd بدهد؛ نمونه: INSTALL.cmd "D:\Python312\python.exe". نیازی به تغییر رجیستری یا PATH توسط نصب‌کننده نیست.

اگر اتصال برقرار نشد

  • پنجره رابط باید باز و وضعیت «فعال، فقط مشاهده» باشد؛ کد را دوباره کپی کنید.
  • اگر نسخه قدیمی حساب‌یار باز است، آن را ببندید؛ هر دو از درگاه 8765 استفاده می‌کنند. برای اجرای دوباره چند ثانیه صبر کنید.
  • سایت را در یک تب مستقل Chrome یا Edge در همان ویندوز باز کنید. تنظیمات دسترسی محلی مرورگر ممکن است اتصال را محدود کند. خطای نمایش‌داده‌شده را برای بررسی بفرستید؛ امنیت ویندوز یا آنتی‌ویروس را غیرفعال نکنید.
  • حسابداری و رابط باید در همان نشست دسکتاپ اجرا شوند. رابط به‌صورت پیش‌فرض بدون Administrator اجرا می‌شود؛ بعضی برنامه‌های دارای سطح دسترسی بالاتر قابل خواندن نیستند.
  • اگر اجزای صفحه خوانده نشدند، روش «برنامه‌های قدیمی (Win32)» را انتخاب و دوباره اتصال و فهرست پنجره‌ها را دریافت کنید. برنامه‌های رسم‌شده روی تصویر ممکن است متن قابل خواندن نداشته باشند.
  • فهرست انتخاب پنجره پس از ۱۰ دقیقه و نشست پس از ۸ ساعت منقضی می‌شود. فهرست را دوباره بگیرید یا رابط را قطع و شروع کنید.
  • خواندن حداکثر ۶۰۰ جزء قابل مشاهده انجام می‌شود؛ سطرهای خارج از صفحه، صفحات دیگر گزارش و فیلدهای محافظت‌شده در این نتیجه تضمین نمی‌شوند.

اطلاعات و حذف نصب

اطلاعات خوانده‌شده از ویندوز مستقیم به مرورگر همین رایانه می‌روند و در این نسخه به سرور سامانه ارسال یا روی دیسک ذخیره نمی‌شوند. دانلود مشخصات فنی فقط نوع و کلاس اجزا، زمان و وضعیت خواندن را دارد؛ متن، تصویر، کد اتصال و عنوان پنجره را ندارد. تصویر اختیاری ممکن است هر اطلاعاتی را که روی همان پنجره دیده می‌شود شامل شود.

پس از کار، در سامانه «قطع و پاک‌کردن» و در رابط «قطع اتصال» را بزنید و پنجره رابط را ببندید. راه‌اندازی هنگام روشن‌شدن ویندوز یا سرویس پس‌زمینه نصب نمی‌شود.

نصب در %LOCALAPPDATA%\NafasyarBridge\0.2.1 انجام می‌شود. برای حذف، رابط را ببندید، فقط همین پوشه نسخه و میان‌بر Nafasyar Bridge را پاک کنید. پوشه‌ها یا دیتابیس حسابداری را تغییر ندهید.

برای مرحله بعد

نام دقیق و نسخه حسابداری، راهنمای گرفتن یک گزارش مورد نظر و نتیجه این اتصال لازم است. سپس یک گزارش مشخص را با جمع کنترل و خروجی مرجع حسابداری تطبیق می‌دهیم. اتصال خودکار به هر نرم‌افزار حسابداری بدون بررسی آن تضمین نمی‌شود.

این نسخه از بخش شناسایی پنجره در حساب‌یار ۰٫۱٫۰ بازنویسی شده است. قابلیت نوشتن فرم نسخه قبلی در این بسته وجود ندارد. نصب واقعی و خواندن حسابداری روی ویندوز شرکت هنوز آزمایش نشده‌اند. شرح بررسی‌های انجام‌شده در VALIDATION.md است.
