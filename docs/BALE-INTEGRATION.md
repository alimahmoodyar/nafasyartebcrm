# اتصال مشترک هم‌نفس به بله

## راه‌اندازی

۱. مهاجرت تکرارپذیر `0029_bale_integration.sql` با روال استقرار قابل اجراست. اگر جدول‌ها یا کنترل‌های اختصاصی بله هنوز ایجاد نشده باشند، ثبت تأییدشدهٔ توکن توسط مدیر، پس از اعتبارسنجی توکن و رمزگذاری آن، فقط اجزای مفقود همین مهاجرت را در یک تراکنش افزایشی ایجاد می‌کند. خواندن وضعیت، کاربر عادی، محیط آزمایش، حالت نگهداری یا توکن نامعتبر هیچ آماده‌سازی انجام نمی‌دهند. جدول، داده، توکن و اتصال موجود حذف یا بازنویسی نمی‌شود؛ اجرای معمول مهاجرت پس از آن نیز داده را حفظ می‌کند. کلید موجود `LLM_CONFIG_ENCRYPTION_KEY` باید ۳۲ بایت تصادفی Base64 باشد. تغییر این کلید بدون بازیابی کلید قبلی، همه توکن‌های ذخیره‌شده با آن را غیرقابل استفاده می‌کند.
۲. در بله یک بازوی اختصاصی شرکت از `@botfather` بسازید. این بازو نباید وب‌هوک اتصال دیگری داشته باشد؛ برنامه آن را حذف یا بازنویسی نمی‌کند.
۳. در تنظیمات LLM و MCP، آیکون مستقل «اتصال بله»، توکن را در ورودی امن وارد کنید و «بررسی توکن و اتصال» را بزنید. توکن در DB رمزگذاری می‌شود؛ HTTP/MCP، ممیزی و خطاها آن را برنمی‌گردانند.
مرحلهٔ اول فقط توکن و دکمهٔ اتصال دارد؛ اتصال حساب شخصی، اتصال پیمانکاران و تغییر توکن/غیرفعال‌سازی پس از راه‌اندازی در بخش‌های جدا باز می‌شوند. تنظیمات Cursor و ساخت توکن مرجع در زیرصفحهٔ دیگر باقی می‌مانند.

۴. هر شخص از پروفایل خودش «اتصال حساب بلهٔ من» را انتخاب می‌کند. لینک ده‌دقیقه‌ای در بله باز می‌شود؛ سپس با «بررسی اتصال»، نام حساب بله می‌آید. کاربر باید همان حساب را از داخل نشست خودش تأیید کند. `/start` به‌تنهایی اتصال فعال یا دسترسی ایجاد نمی‌کند. برای تأمین‌کنندگان/پیمانکاران، مدیر همین فرایند را برای پروندهٔ موجود تأمین‌کننده انجام می‌دهد و هویت مخاطب را قبل از تأیید بررسی می‌کند.
۵. آزمون ارسال، متن ثابت و فاقد اطلاعات کاری را فقط به حساب تأییدشدهٔ همان کاربر می‌فرستد. موفقیت ارسال به معنی خوانده‌شدن یا تأیید واریز بانکی نیست.

## دریافت پیام

مسیر مشترک فعلی `pollBale` از `getUpdates` استفاده می‌کند؛ endpoint عمومی وب‌هوک نداریم و امضای مستندنشدهٔ بله را فرض نکرده‌ایم. دکمهٔ بررسی اتصال همین مسیر را فراخوانی می‌کند. برای دریافت خودکار، زمان‌بند سرور هر دقیقه `POST /api/integrations/bale/poll` را با `Authorization: Bearer <TASK_SCHEDULER_TOKEN>` اجرا کند. توکن زمان‌بند فقط در تنظیمات امن سرویس زمان‌بند نگهداری شود. قفل دریافت، offset پایدار و ثبت یک‌بارهٔ نامزد پیوند، دریافت‌های هم‌زمان و تکراری را کنترل می‌کنند. اکنون فقط پیام `/start` برای اتصال پردازش می‌شود؛ قابلیت‌های کاری دریافت پیام باید در همین مسیر، با مجوز و handler دامنهٔ خود اضافه شوند.

## توسعهٔ فرایندهای بعدی

`lib/bale-transport.ts` تنها آداپتور ارتباط با میزبان ثابت رسمی است. `lib/bale.ts:sendBale` سرویس مشترک متن و فایل است. فرایند دامنه باید:

- کاربر، پروندهٔ واقعی، گیرنده و همان پیوست را قبل از فراخوانی کنترل کند و callback اجباری `authorize` را پیاده کند. API عمومی ارسال آزاد، chat_id دلخواه، لینک فایل اینترنتی یا کلید R2 دلخواه وجود ندارد.
- `id` تصادفی UUID ثابت برای همان اقدام، `linkId` تأییدشده، `purpose` و `sourceRef` پرونده را ارسال کند. برای فایل، بایت‌های خوانده‌شده از مسیر مجاز خصوصی، نام و MIME بدهد. سقف محافظه‌کارانهٔ برنامه ۲۰ مگابایت است؛ در outbox فایل یا متن مالی ذخیره نمی‌شود، فقط هش محتوا و سابقهٔ نتیجه می‌ماند.
- نتیجهٔ `sent`، `failed`، `unknown` یا ارسال در جریان را به‌درستی نشان دهد. درخواست تکراری با همان شناسه دوباره ارسال نمی‌شود؛ تغییر محتوا/گیرنده با همان شناسه رد می‌شود. حالت نامشخص یا قطع فرایند بعد از شروع ارسال نباید خودکار بازفرستاده شود. فقط پس از بررسی اپراتور، اقدام تازه با شناسه تازه قابل طرح است.
- دستیار از ابزارهای مشترک `get_bale_connection` و `bale_connection_apply` استفاده می‌کند. تنظیم توکن از گفتگو ممنوع و فقط فرم امن مرورگر مجاز است. اتصال به هر فرایند کاری ابزار MCP همان فرایند را نیز نیاز دارد.

این نسخه زیرساخت است: هنوز ارسال خودکار رسید بانکی، اعلان کارتابل یا فرمان کاری بله فعال نشده؛ هرکدام باید از مجوز و پروندهٔ اصلی همان دامنه تغذیه شوند.

## داده و محیط آزمایش

تمام عملیات بیرونی در training، rolePreview و profileReview مسدودند. تنظیمات و اتصال‌های تأییدشده در هر دو پاک‌سازی شرکت حفظ می‌شوند؛ پیوندهای موقت و سابقهٔ ارسال در هر دو محدوده پشتیبان و پاک می‌شوند. هیچ فایل جدیدی در R2 ایجاد نمی‌شود. freeze triggerها نوشتن هنگام نگهداری را مسدود می‌کنند؛ شروع نگهداری در حین یک ارسال تازهٔ در جریان تا پایان درخواست/گذشت دو دقیقه مسدود است تا حذف سابقه با ارسال هم‌زمان نشود. ارسال گیرندهٔ قطع‌شده و اتصال بازوی قبلی مجاز نیست. نامزدهای منقضی هرگز قابل تأیید نیستند.

مرجع پروتکل: https://docs.bale.ai/ (Bot API معمولی؛ API کسب‌وکاری و ارسال انبوه استفاده نمی‌شود).
