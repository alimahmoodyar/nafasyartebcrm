# نصب هم‌نفس روی اندروید

این انتشار PWA است، APK یا برنامه Play Store نیست. در شاخه sites/nafasyar-trace قرار دارد؛ شاخه .NET main جداست و با این پوش منتشر نمی‌شود.

## کاربر
آدرس HTTPS شرکت را در Chrome اندروید باز کنید، وارد حساب شوید و از منو «نصب روی گوشی» را بزنید. اگر دکمه نصب فعال نبود از منوی مرورگر Install app / Add to Home screen استفاده کنید. نصب فقط با تأیید خود کاربر انجام می‌شود. حساب، کارتابل و سطح دسترسی همان نسخه وب هستند.

## استقرار شرکت
- همان خروجی وب را با HTTPS معتبر در ریشه دامنه منتشر کنید. مسیرهای /manifest.webmanifest، /sw.js، /offline.html و /brand/hamnafas-*.png باید بدون ورود و بدون بازنویسی به صفحه HTML در دسترس باشند؛ این فایل‌ها هیچ داده شرکتی ندارند.
- /sw.js را با Content-Type جاوااسکریپت و Cache-Control: no-cache ارائه کنید. فایل manifest با application/manifest+json ارائه شود. فایل‌های عمومی فوق نباید پشت auth سفارشی سرور به HTML ورود تبدیل شوند. خود صفحات کاری و API همچنان احراز هویت می‌خواهند.
- نشانی باید از اینترنت گوشی قابل دسترس باشد یا VPN شرکت برقرار باشد. نصب به معنی رفع محدودیت شبکه یا محدودیت مخاطبان میزبان نیست. نسخه خصوصی Sites فقط برای مخاطبان مجاز آن است؛ همکاران باید آدرس سرور شرکت یا میزبانی مجاز خودشان را استفاده کنند.
- service worker مسیر ریشه را شبکه‌ای می‌خواند و فقط اگر شبکه شکست خورد صفحه عمومی قطع اتصال نشان می‌دهد. هیچ API، فایل یا پاسخ احراز هویت، داده و HTML شخصی کش نمی‌شود. کش قدیمی فقط با پیشوند اختصاصی خودش پاک می‌شود. داده‌های ذخیره‌شده قبلی برنامه با این قابلیت تغییر نمی‌کنند.
- نیاز به کلید جدید، APK امضاشده یا migration دیتابیس ندارد. کاربر با بازکردن مجدد آنلاین، کد جدید سرور را دریافت می‌کند؛ هنگام بروزرسانی فرم باز را خودکار رفرش نمی‌کنیم.
- اعلان فعلی درون برنامه است، push/background sync پیاده نشده. ارسال آفلاین وجود ندارد. وضعیت online فقط وضعیت شبکه مرورگر است و تضمین سلامت سرور نیست.

## تأیید نهایی روی گوشی واقعی
۱. با حساب محدود از HTTPS شرکت نصب کنید و از آیکون اجرا کنید؛ نوار آدرس نباید در حالت standalone دیده شود.
۲. کارتابل/مأموریت مجاز را باز و یک فایل آزمایشی ارسال کنید؛ کاربر نباید به مأموریت دیگران دسترسی داشته باشد.
۳. اینترنت را قطع و برنامه را باز کنید: صفحه قطع اتصال؛ هیچ پاسخ داده از service worker برنگردد. اینترنت را وصل و دوباره تلاش کنید.
۴. خروج و ورود با حساب دیگر؛ سوابق محدود به حساب جدید باقی بماند.
۵. انتشار نسخه بعدی؛ بازکردن آنلاین باید تغییرات را دریافت کند.

تست خودکار قرارداد manifest، محدوده رهگیری شبکه و عدم کش داده در tests/mobile-install.cjs است. تأیید نصب واقعی اندروید نیازمند گوشی و سرور HTTPS است.
